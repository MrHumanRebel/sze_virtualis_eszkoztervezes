# Valódi Siemens-képernyőképek

Egyelőre nincsenek bizonyított alkalmazásképernyőképek. A sikeres helyi Plant Simulation-futtatás után öt képet exportálunk a program saját copyBitmapToFile függvényével: főmodell, három részmodell, állomásstatisztika.

Valódi képek és a SHA256 manifest csak a submissions/<NEPTUN>/screenshots helyre kerülnek. Szintetikus vagy más modellből származó kép nem megfelelő.
