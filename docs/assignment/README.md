# Az eredeti feladatlap

A kapott PS beadandó.pdf az eredeti kétoldalas feladatlap.

A docs/generated/Feladatkiiras_atirat.pdf a szöveges, újraszedett átirata, nem az eredeti dokumentum. Az eredeti, változatlan állományt a Windowsos feltöltő külön tudja betenni ide: -OriginalAssignmentPdf "C:\\path\\PS beadandó.pdf".
